## 📌 Sobre o Projeto

O **Springboot Ebac** é um projeto desenvolvido com foco em boas práticas de programação, estrutura limpa e organização de código.

---

## 🛠️ Tecnologias Utilizadas

- **Linguagem Principal**: Java (JDK 17+)
- **Framework**: Spring Boot (Spring Web MVC, Spring Data JPA)
- **Gerenciador de Dependências**: Apache Maven

---

## 🚀 Como Executar o Projeto

### Pré-requisitos
- Java Development Kit (JDK) 17 ou superior
- Git instalado na máquina

### Passo a Passo

```bash
# 1. Clonar o repositório
git clone https://github.com/RafaelLimaJ/SpringbootEbac.git

# 2. Acessar o diretório do projeto
cd SpringbootEbac

# 3. Compilar e executar com Maven
./mvnw spring-boot:run # ou mvn clean install
```

---
